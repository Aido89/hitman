# Галерея — как добавить фото и видео

## Фото

Просто положите файл в нужную папку. Он появится на сайте автоматически —
**править код не нужно**.

```
static/img/gallery/
├── streaming/   Трансляции: режиссёрские, пульты, эфиры
├── events/      Мероприятия: конференции, турниры, сцена
├── podcast/     Студия и подкасты
├── infra/       IT-инфраструктура: стойки, серверные, сети
├── training/    Обучение: занятия, аудитории
└── photo/       Фото- и видеосъёмка
```

Форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`

### Подпись под фото

Часть имени файла после `--` становится подписью:

| Имя файла | Подпись на сайте |
|---|---|
| `boxing-ring--Финал чемпионата World Boxing.jpg` | Финал чемпионата World Boxing |
| `IMG_2841.jpg` | (без подписи — фото всё равно покажется) |

Подпись не обязательна. Фото без подписи лучше, чем фото, которое не загрузили
из-за возни с именем.

**Не используйте в именах:** `:` `/` `\` `?` `#` — ломают адрес файла.

### Порядок

Фото сортируются по дате изменения файла — новые сверху. Чтобы поднять фото
наверх: `touch «имя файла.jpg»`.

### Размер

Перед загрузкой ужмите крупные фото, иначе страница будет грузиться долго:

```bash
sips -Z 1600 *.jpg          # ужать до 1600px по длинной стороне
```

Ориентир: 200–500 КБ на фото.

## Видео

Видео живут на YouTube — так не тратится место и трафик сервера.
Добавляются в `pages/gallery.py`, список `VIDEOS`:

```python
VIDEOS = [
    {'youtube_id': 'dQw4w9WgXcQ',      # часть после v= в ссылке
     'title': 'Финал чемпионата',
     'category': 'streaming',           # папка из списка выше
     'caption': 'Многокамерная трансляция'},
]
```

Плеер грузится только по клику — до этого показывается обложка, страница
не тяжелеет.
